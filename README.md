# سامانه جامع مدیریت و ارتباط با مشتریان ووکامرس (CRMWP)
### WooCommerce Management & CRM Platform — Release Candidate 1.0.0-RC1

یک سامانه پیشرفته، امن و با عملکرد بالا برای مدیریت یکپارچه فروشگاه‌ها و مشتریان ووکامرس با معماری Standalone مبتنی بر PHP 8.2+ و Vue 3.

---

## ویژگی‌های کلیدی

- **طراحی کاملاً مستقل (Standalone Architecture)**:
  - عدم نیاز به نصب افزونه درون وردپرس یا دسترسی مستقیم دیتابیس به جداول ووکامرس.
  - ارتباط امن و استاندارد از طریق WooCommerce REST API v3 و HPOS.
  - پشتیبانی کامل از هاست‌های اشتراکی (cPanel/DirectAdmin/Plesk) و سرورهای اختصاصی لینوکس.
  - بدون نیاز زمان اجرا (Runtime) به Node.js، npm، Composer، Redis، RabbitMQ یا Docker.

- **مدیریت چندفروشگاهی (Multi-Store)**:
  - اتصال همزمان به چندین فروشگاه ووکامرس با ارزها و مشخصات متفاوت.
  - ایزولاسیون کامل داده‌ها، کش‌ها و سطح دسترسی کاربران (Anti-IDOR).
  - کلیدهای رمزنگاری‌شده با استاندارد AES-256-CBC و امضای HMAC.

- **مدیریت پیشرفته محصولات و تنوع‌ها (Variable Products & Variations)**:
  - تفکیک کامل و نمایش محصولات متغیر به همراه تک‌تک تنوع‌ها (Variations).
  - مدیریت موجودی، قیمت‌های حراج و عادی، SKU، ابعاد و وضعیت انبار در سطح والد و تنوع.

- **موتور عملیات گروهی (Bulk Operations Engine)**:
  - پشتیبانی کامل از ویرایش دسته‌جمعی محصولات ساده، متغیر و تنوع‌ها.
  - امکان انتخاب دامنه هدف: فقط محصولات والد، فقط تنوع‌ها، یا هر دو.
  - پیش‌نمایش دقیق تغییرات پیش از اعمال، کنترل تکرار (Idempotency Key)، پردازش تکه‌ای (Chunking) و ثبت لاگ‌های حسابرسی (Audit Trail).

- **مدیریت ارتباط با مشتریان (CRM)**:
  - بخش‌بندی پویای مشتریان (Segments)، برچسب‌گذاری چندرنگ (Tags)، وظایف (Tasks) و یادداشت‌ها.
  - خط زمانی فعالیت‌ها (Activity Timeline) و هماهنگی کامل با سفارش‌های مشتری.

- **اتوماسیون و گردش کار (Workflow Engine)**:
  - تریگرهای متنوع (ثبت سفارش، بروزرسانی موجودی و...)، شروط تودرتوی پیشرفته (AND/OR).
  - متغیرهای پویا و اقدامات خودکار بدون ریسک گردش بی‌پایان (Loop Prevention).

- **رابط کاربری مدرن، فارسی و آفلاین**:
  - فونت محلی وزیرمتن (Vazirmatn Woff2) در ۹ وزن بدون وابستگی به Google Fonts یا اینترنت.
  - آیکون‌های محلی Iconsax، پشتیبانی از حالت روز/شب (Light/Dark Mode)، طراحی کاملاً ریسپانسیو و ارقام فارسی.

## پیش‌نیازهای سرور

| پیش‌نیاز | حداقل نسخه | نسخه توصیه‌شده |
| :--- | :--- | :--- |
| **PHP** | 8.2 | 8.3 یا 8.4 |
| **MariaDB / MySQL** | MariaDB 10.6+ / MySQL 8.0+ | MariaDB 11.x / 13.x |
| **اکستنشن‌های PHP** | `pdo`, `pdo_mysql`, `openssl`, `mbstring`, `curl`, `json`, `session` | فعال به صورت پیش‌فرض |
| **وب‌سرور** | Apache 2.4, LiteSpeed, Nginx | Apache / LiteSpeed (پشتیبانی از `.htaccess`) |
